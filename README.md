# Credit Gaps and Debt-Service Pressures in Asia-Pacific
## A Macro-Financial Research and Robustness Pipeline

### 1. Project Overview

This project investigates the relationship between credit gaps and debt-service ratios (DSRs) in Australia, Japan, and the Republic of Korea using quarterly data from the Bank for International Settlements (BIS).

The analysis examines whether changes in credit gaps are associated with changes in debt-service burdens, with particular attention to the distinction between household and non-financial corporate sectors.

The project combines data inspection, validation, time-series analysis, correlation analysis, robustness checks, and block-bootstrap inference in a reproducible Python pipeline.

**Research question:** How strongly are changes in credit gaps associated with changes in debt-service ratios across selected Asia-Pacific economies, and does this relationship differ between households and non-financial corporations?

### 2. Data Sources

The project uses the following BIS datasets:

- [BIS Credit-to-GDP Gaps](https://data.bis.org/topics/CREDIT_GAPS)
- [BIS Debt Service Ratios](https://data.bis.org/topics/DSR)

The raw CSV files are stored locally in `data/raw/` and are excluded from version control.

#### Main variables

- **Credit gap (C):** the deviation of the credit-to-GDP ratio from its estimated long-term trend, expressed in percentage points of GDP.
- **Debt-service ratio (DSR):** debt-service payments relative to income, expressed as a percentage.
- **Households (H):** households and non-profit institutions serving households.
- **Non-financial corporations (N):** the non-financial corporate sector.
- **Private non-financial sector (P):** an aggregate covering households and non-financial corporations; it is not treated as an independent sector in sector-level comparisons.

The analysis uses quarterly observations and country-specific samples. Comparisons are restricted to compatible observations when datasets are merged.

### 3. Methodology

The analytical workflow includes:

1. **Data inspection and selection** — inspect source files and select relevant countries, indicators, and sectors.
2. **Data validation** — check observations, duplicate keys, series consistency, and quarterly continuity.
3. **Exploratory analysis** — plot credit gaps and debt-service ratios and examine descriptive statistics.
4. **Dataset construction** — merge compatible quarterly observations and calculate changes where appropriate.
5. **Correlation analysis** — estimate Pearson and Spearman correlations between quarterly changes.
6. **Robustness checks** — examine alternative specifications, influential quarters, sector definitions, and rolling correlations.
7. **Bootstrap inference** — estimate uncertainty using moving-block bootstrap methods designed to preserve some short-run time dependence.
8. **Sector comparison** — estimate paired differences between corporate and household correlations and assess their sensitivity to block length.

### 5. Analysis Pipeline

The scripts in `src/` cover the following stages:

| Scripts | Purpose |
|---|---|
| `01_inspect_credit_gap.py` – `04_plot_credit_gap.py` | Credit-gap inspection, validation, quarterly continuity, and visualisation |
| `05_inspect_dsr.py` – `07_analyze_dsr.py` | DSR inspection, visualisation, and descriptive analysis |
| `08_merge_credit_gap_dsr.py` – `11_test_influential_quarters.py` | Dataset merging, correlation robustness, combined plots, and influential-quarter analysis |
| `12_analyze_dsr_sectors.py` – `14_analyze_rolling_correlations.py` | Sector-level analysis, sector robustness, and rolling correlations |
| `15_bootstrap_correlation_inference.py` – `16_bootstrap_block_sensitivity.py` | Bootstrap confidence intervals and block-length sensitivity |
| `17_bootstrap_sector_difference.py` – `18_plot_sector_comparison.py` | Corporate-versus-household correlation differences and visualisation |

Run the scripts from the project root, in numerical order, after placing the required BIS source files in `data/raw/`. The scripts use paths derived from their own file locations, but each stage may depend on processed outputs generated by earlier stages.

### 6. Selected Findings

The current analysis of quarterly changes reports the following Pearson correlations between the credit gap and the aggregate private non-financial sector DSR:

| Country | Pearson correlation |
|---|---:|
| Australia | 0.408 |
| Japan | 0.677 |
| Republic of Korea | 0.671 |

Sector-level Pearson correlations show a different pattern across the three countries:

| Country | Household DSR | Corporate DSR |
|---|---:|---:|
| Australia | 0.163 | 0.578 |
| Japan | -0.158 | 0.825 |
| Republic of Korea | 0.102 | 0.676 |

In this sample, the correlation between quarterly changes in the credit gap and corporate DSR is higher than the corresponding household correlation in all three countries.

Paired moving-block bootstrap analyses also report positive corporate-minus-household correlation differences across the tested block lengths. These results describe associations in the analysed samples and should not be interpreted as evidence of causality.

### 7. Robustness and Validation

The project includes:

- checks for duplicate country-series-quarter observations;
- checks of quarterly continuity;
- validation of compatible observations before merging;
- Pearson and Spearman correlation comparisons;
- influential-quarter sensitivity analysis;
- rolling-correlation analysis;
- sector-level robustness checks;
- moving-block bootstrap confidence intervals;
- sensitivity analysis across bootstrap block lengths;
- automated tests for statistical functions, reproducibility, input validation, and correlation bounds.

```powershell

```

Continue with the subsequent scripts after checking that each stage completes successfully and generates the expected outputs.

Run the automated tests:

```powershell
python -m pytest -v
```

### 10. Limitations

- Correlations identify statistical association, not causal effects.
- Results depend on sample coverage, data definitions, and the treatment of quarterly changes.
- Credit gaps are estimated relative to a trend and may be revised as new observations become available.
- Bootstrap confidence intervals depend on assumptions about temporal dependence and the selected block length.
- Three country case studies do not establish that the same relationships hold across all economies or periods.

### 11. Reproducibility

The analysis scripts, selected processed outputs, figures, and automated tests are version-controlled. Raw BIS source files are kept locally and excluded from Git.

For reproducibility, users should record the source-data retrieval date, preserve the original BIS files, and rerun the pipeline from the initial inspection stage when updating the data.
